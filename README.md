# FishRadar · 摸鱼雷达

FishRadar 是一个 macOS 本地桌面应用，使用摄像头观察画面中的人员，并通过屏幕上的小箭头提示左右方向的变化。它可以作为办公室的简易后视镜，不要求用户为应用调整坐姿或摄像头角度。

目前项目处于**可试用原型**阶段。提示基于摄像头画面估计，不能覆盖身体、椅背等物体遮挡的区域，也不能保证识别出每个人。

## 功能

- 在菜单栏和屏幕上显示左右箭头，提示画面中检测到的人员及疑似靠近趋势。
- 提供可手动打开的无边框后视镜；支持拖动、设置大小和透明度、边缘吸附及位置记忆。
- 使用默认摄像头，可暂停或恢复检测；暂停时停止摄像头。
- 设置有效区域、忽略区域和重点区域，减少固定工位等背景干扰。
- 提供可选的实验监控，记录资源使用情况，支持手动标记测试结果和单独开启照片抓拍。
- 使用 macOS Vision 在本地处理画面，不需要网络，也不采集麦克风音频。

## 开始使用

需要 macOS、摄像头和 Apple Command Line Tools。本地编译和运行不需要 Apple 开发者证书或公证。

打开「终端」，依次执行：

```bash
# 如果尚未安装，请先安装 Apple Command Line Tools
xcode-select --install

# 下载源码并进入项目目录
git clone https://github.com/mchenziyi/FishRadar.git
cd FishRadar

# 编译并启动
./scripts/build.sh
open build/FishRadar.app
```

如果已经安装 Command Line Tools，可以跳过第一步。构建脚本会在本机生成并临时签名 `build/FishRadar.app`；如需放入「应用程序」，可以在 Finder 中将该 App 拖到「应用程序」文件夹。

目前只在 Apple Silicon Mac 上验证过构建和运行，Intel Mac 尚未验证。编译好的 App 未经 Apple 开发者证书签名和公证，直接分发给其他 Mac 时可能被 Gatekeeper 阻止打开。

首次启动时允许摄像头访问。应用在菜单栏运行，点击菜单栏上的左右箭头可以打开设置、显示或隐藏后视镜、暂停检测或退出。

如果需要暂停摄像头，选择「暂停检测」；锁屏或休眠时应用也会暂停，之后可以从菜单栏手动恢复。

## 箭头提示

左右箭头分别表示画面中对应方向的检测状态，屏幕上的箭头可以拖动。

| 颜色 | 含义 |
| --- | --- |
| 白色 | 当前未检测到需要提示的目标 |
| 绿色 | 检测到人员目标 |
| 黄色 | 疑似正在靠近 |
| 红色 | 人员框的相对变化更明显 |
| 灰色 | 检测暂停或不可用 |

黄色和红色由连续画面中人员框的大小变化估算，**不是精确的距离测量**。白色也不代表周围一定没有人。人员持续约 5 秒基本不动时会暂时忽略；这个时间可以在设置中调整。

后视镜默认不会因提醒自动弹出，需要时可以手动显示。

## 设置

点击菜单栏箭头，选择「设置…」：

- **常规**：通过滑块调整后视镜大小和不透明度；设置静止忽略时间、靠近检测灵敏度、快捷键和登录后启动。
- **检测区域与预览**：在实时画面中拖动绘制矩形区域。有效区域限制检测范围，忽略区域排除固定座位等位置，重点区域使用更敏感的靠近判断。每种区域各支持一个矩形；区域按人员检测框的中心判断，忽略区域优先。
- **实验监控**：可选开启资源采样、记录测试结果，以及单独开启诊断照片保存。

大小和透明度滑块立即生效；检测参数和快捷键需要点击「保存检测与快捷键设置」。登录后启动取决于 macOS 登录项状态，如果系统拒绝会显示提示。

### 默认快捷键

| 操作 | 快捷键 |
| --- | --- |
| 显示或隐藏后视镜 | Control + Option + R |
| 暂停或恢复检测 | Control + Option + P |
| 显示或隐藏悬浮箭头 | Control + Option + H |

可以在设置中修改字母；修饰键固定为 Control + Option。如果快捷键被占用，需要更换字母。

## 实验监控与隐私

监控默认关闭。手动开启后，应用会在本机记录自身进程的 CPU、内存采样和检测状态变化；也可以在设置中手动标记测试场景及结果。资源数据不包含系统共享的摄像头服务。

**诊断照片需要另行勾选开启**。开启后，箭头亮起或颜色升级时会保存产生该判断的画面；手动记录测试时也会拍照。照片与日志可用于分析提醒是否符合预期，画面可能包含使用者和周围人员，请自行管理这些文件。

记录保存在：

```text
~/Library/Application Support/FishRadar/
```

日志每份约 5 MiB，保留当前和上一份，之后轮替。照片位于 `photos/`，最多保存 200 张；达到上限后停止拍照并提示，不自动删除旧照片。关闭监控或重新启动应用后，照片保存会关闭。应用不上传画面，不保存视频，也不建立人员身份数据库。

## 已知限制

- 应用使用系统默认摄像头，暂不支持在应用内切换设备。
- 自身排除依靠画面位置和大小；侧身、离座、多人重叠或遮挡时可能误判。
- 固定工位上的活动可能触发提醒，可尝试设置忽略区域。
- 横向路过、检测框抖动或目标被遮挡时，靠近趋势和颜色可能判断不准。
- 摄像头异常后尚不支持自动恢复；可以检查权限或设备后，手动暂停并恢复检测。
- 尚未完成 PRD 中的误报率、提醒延迟和 24 小时稳定性等完整验收。

## 开发与测试

项目使用 Swift、AppKit、AVFoundation 和 Vision。`Sources/` 存放应用代码，`Tests/` 包含检测逻辑和诊断记录测试。

```bash
swiftc Sources/ApproachTracker.swift Tests/main.swift -o /tmp/fishradar-approach-tests
/tmp/fishradar-approach-tests

swiftc Sources/Diagnostics.swift Tests/Diagnostics/main.swift -o /tmp/fishradar-diagnostics-tests
/tmp/fishradar-diagnostics-tests
```

测试使用模拟数据和临时文件，不需要保存摄像头画面。
